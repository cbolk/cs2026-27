# Lezione: Struttura, variabili e tipi

## Dettaglio

+ struttura minima di un programma C
+ dichiarazione di variabili
+ tipi di base: `int`, `float`, `char`

## Esercizi svolti

::: exefatti

Scrivere un programma C ANSI 89 che dichiara due interi, li legge da input
e ne stampa la somma.

```C
#include <stdio.h>

int main(void)
{
	int a, b;

	scanf("%d %d", &a, &b);
	printf("%d\n", a + b);

	return 0;
}
```

[file](../codice/001.somma.c)

:::

## Esercizi proposti

::: exepro

Scrivere un programma C ANSI 89 che dichiara tre variabili di tipo diverso
(`int`, `float`, `char`) e ne stampa i valori con il formato corretto.

:::
