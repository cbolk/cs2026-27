Least frequent digit

Given an integer number, find the digit that occurs the fewest times among the present digits. If several digits share that minimum count, return the largest of them.

solving algorithm

Build a descending list containing each digit at most once. Then count directly in num how many times each listed digit occurs. Stop as soon as the minimum frequency becomes 1.

Output —
Examples

Digits 0–9 only. Any change restarts from the first step.
