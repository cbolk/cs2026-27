### Least frequent digit in nymber

Given an integer number, find the digit that occurs the fewest times among the present digits. If several digits share that minimum count, return the largest of them.

#### Version A

solving strategy: Keep a counter for each possible digit in the number. For every digit in the input number, increment the corresponding counter. Starting from te counters of 9s, find the counter with the smallest count.

```bash
initialise 10 counters to 0
acquire num
for every digit in num
	increment corresponding counter
	start from counter of 9s
while the counter value is 0
	go to the next counter
min_occ = value of the counter
min_digit = digit of the counter
if min_occ is greater than 1
	for all remaining counters
		if the counter value is greater than 0 and smaller than min_occ
			min_occ = value of the counter
			min_digit = digit of the counter
			if min_occ is 1, interrupt iterations
display min_digit
```

+ Data structure: ten counters
+ Input number analysis (digit extraction): only once
+ Computation: the digits of the input number are extracted once, and te counters are scanned once
+ Optimization: analysis interrupted as soon as result is found

#### Version B

solving strategy: count how many times each possible digit appears in the input number and keep track of the smallest number of occurrences greater than 0 and corresponding to the highest digit.


```bash
acquire num
for every value v from 9 to 0
	count how many times it appears in num
	if it is greater than 0
		min_occ = number of times
		min_digit = value
		interrupt iterations
if min_occ greater than 1
	for every value v from min_digit-1 to 0
		count how many times it appears in num
		if it is greater than 0 and smaller than min_occ
			min_occ = number of times
			min_digit = value
			if min_occ is 1, interrupt iterations
display min_digit
```

+ Data structure: none
+ Input number analysis (digit extraction): performed ten times
+ Computation: the input number digits are extracted ten times
+ Optimization: analysis interrupted as soon as result is found



#### Version C

solving strategy: for every digit in the input number, if we have not already found it, count how many times it appears in the number and keep track of the smallest number of occurrences and corresponding to the highest digit 


```bash
list of digit_list set to empty
acquire num
for each digit in num
	if it is not in digit_list
		add it in a descending sorted way in digit_list
take the first digit d in digit_list
count how many times it appears in num: min_occ
min_digit = d
if min_occ greater than 1
	for every remaining digit d in digit_list
		count how many times it appears in num: num_occ
		if it is smaller than min_occ
			min_occ = num_occ
			min_digit = d
			if min_occ is 1, interrupt iterations
display min_digit
```

+ Data structure: list
+ Input number analysis (digit extraction): one to scan of the input and one for every different digit in the input number to count occurrences
+ Computation: the created list is scanned once and for each unique digit, the number of occurrences is counted (the remaining part of the input number is analysed)
+ Optimization: analysis interrupted as soon as result is found

#### Version D

solving strategy: build a list of unique digits appearing in the input number, sorted in a descending order. For each digit count how many times it appears in the input number and find the smallest number of occurrences.


```bash
list of digit_list set to empty
acquire num
for each digit in num
	if it is not in digit_list
		add it in a descending sorted way in digit_list
take the first digit d in digit_list
count how many times it appears in num: min_occ
min_digit = d
if min_occ > 1
	for every remaining digit d in digit_list
		count how many times it appears in num: num_occ
		if num_occ is smaller than min_occ
			min_occ = num_occ
			min_digit = d
			if min_occ is 1, interrupt iterations
display min_digit
```

+ Data structure: list, maintained sorted and with no duplicates
+ Input number analysis (digit extraction): one scan of the input and one for every different digit in the input number to count occurrences
+ Computation: the created list is scanned once and for each unique digit, the number of occurrences is counted (input number is analysed)
+ Optimization: analysis interrupted as soon as result is found

#### Version E

solving strategy: Extract all digits and insert them into a descending sorted list. Measure each subsequence of identical elements length and find the shortest one.


```bash
list of digit_list set to empty
acquire num
for each digit in num
	add it in a descending sorted way in digit_list
start from the beginning of the list
set the length of the subsequence of identical elements to 1
while there is a subsequent element and it is equal to the initial one
	increment the length of the subsequence
	move to the next element in the list
min_occ = length of the subsequence
min_digit = first element of the list
move to the first element of the next subsequence
while min_occ > 1 and there are elements remaining
	curr_dig = current digit in the list
	set the length of the subsequence of identical elements to 1
	while there is a subsequent element in the list and it is equal to curr_dig
		increment the length of the subsequence
		move to the next element in the list
	if length of the subsequence is smaller than min_occ
		min_occ = num_occ
		min_digit = curr_dig
		if min_occ is 1, interrupt iterations
	move to the first element of the next subsequence
display min_digit
```

+ Data structure: list, maintained sorted
+ Input number analysis (digit extraction): input number is scanned only once
+ Computation: the created list is scanned once to compute subsequence of identical adjacent elements
+ Optimization: analysis interrupted as soon as result is found

### ATM

Given a withdrawal amount that is a multiple of €5, determine the minimum number of banknotes required using €50, €20, €10 and €5 notes, and display the quantity of each denomination.

Solving strategy: Use as many €50 bills as possible, then cover the remaining amount with as many €20 bills as possible, cover the remaining amount with as many €10 bills as possible, and finally use €5 bills.

```bash
acquire amount
n50 = integer (amount / 50)
rem = amount − n50 * 50
n20 = integer (rem / 20)
rem = rem − n20 * 20
n10 = integer (rem / 10)
n5 = (rem − n10 * 10) / 5
display n50, n20, n10, n5
```

using operators from python

```bash
acquire amount
n50 = amount // 50
rem = amount % 50
n20 = rem // 20
rem = rem % 20
n10 = rem // 10
n5 = (rem % 10) // 5
display n50, n20, n10, n5
```

Introducing an additional control to avoid the division requires the evaluation of an additional condition and other assignments. 


```bash
acquire amount
n50 = amount // 50
rem = amount % 50
if rem greater than 0
	n20 = rem // 20
	rem = rem % 20
	if rem greater than 0
		n10 = rem // 10
		n5 = (rem % 10) // 5
	otherwise
		n10 =  0
		n5 = 0
otherwise
	n20 = 0
	n10 =  0
	n5 = 0	
display n50, n20, n10, n5
```
